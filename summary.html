deduplication.tech — handoff

HackerNoon site: one word, two meanings, data on which meaning owns it. State as of Oct 22, 2026, for continuing in Cursor.

What exists

  • Static site generator (deduplication-site/build.mjs, Node, no deps) → dist/: 636 pages — 632 term pages at /term/{term}/{original}/{duplicate}/ (also the H1 and title), home with search + word cloud + leaderboards, 12 field pages ranked by popularity, Method page (incl. colour system), All terms, Terms & Conditions, sitemap, robots, vercel.json.
  • Term database: src/terms-100/200/300.txt + terms.txt, pipe-delimited: term|cat|origLabel|origWiki|origYear|dupLabel|dupWiki|dupYear|note|origDef|dupDef|qA|qB.
  • Data: src/data.json = Wikipedia monthly pageviews 2015-07→now for 630 terms, collected in your browser. Verdict = duplicate's 12-month share: >60% green (duplicate wins), <40% grey (original holds), 40–60% amber (contested), no data dim grey.
  • Preview: node build.mjs --preview → single-file SPA (published as the claude.ai artifact).
  • Pipeline (started): deduplication-pipeline/ — terms export, matcher, labeler, HF upload helper. Runners + workflows still TODO (see its README).

Decisions made

CutHacker News (your call), Google Trends (unofficial API rate-limits; official API is alpha by application — you were filling the form), tug-of-war and pulsing cloud animations (hard to read). Kept: slight grow on hover.
Spoken dataYODAS (YouTube, CC BY 3.0, attribute) + OpenSubtitles (Movies & TV; publish counts only, raw text stays private). Dropped MediaSum/GigaSpeech (non-commercial) and other spoken-media sets.
ComputeFree: GitHub Actions on a public repo (parallel matrix jobs, 6h each) + Hugging Face datasets for storage. HF Spaces compute now needs a paid plan.
NamesGitHub hackernoon/deduplication (folders: youtube/, tv-and-movies/, counts/). HF datasets hackernoon/deduplication-youtube (public), -tv-and-movies (private), -counts (public).
BlueskyPossible replacement for HN: search needs a free account + app password; Jetstream firehose is free but forward-only. Untested.

  2. Create the repo + datasets under hackernoon on GitHub and Hugging Face (create a hackernoon HF org if it doesn't exist — the HF owner list only showed your account). Add a write token as GitHub secret HF_TOKEN.
  3. Finish the three runners listed in the pipeline README. Verify the YODAS file layout first (text JSON shards under data/en*/text/) so jobs never download audio.
  4. Pilot 20 terms (MTS, Cloud, Bug, Python, Rust, Kernel…), hand-check ~50 labels each on a tiny review page (Approve / Flip / Neither). Tune MARGIN; add a second small model for "unsure".

  6. Fix known data limits: 113 terms share a Wikipedia article with another term (e.g. Kubernetes ×6) — spoken data will separate them; give each its own disambiguated article where possible.

Gotchas

  • Never publish OpenSubtitles dialogue — counts and shares only.
  • Credit YODAS (CC BY 3.0) on Method and T&C (already written).
  • Acronyms match case-sensitively (MTS ≠ "mts"); everything else case-insensitive whole word.
  • Keep the preview under 16 MB (it's ~14 MB) or drop it and use the real deploy.
